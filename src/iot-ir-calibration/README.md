## Автоматизированная калибровка ИК-дальномера с помощью (HC-SR04)

Этот проект реализует систему построения математической модели для аналогового инфракрасного датчика (TCRT5000/KY-033). Поскольку ИК-датчики имеют нелинейную зависимость выходного напряжения от расстояния, система использует ультразвуковой датчик HC-SR04 в качестве эталона для «обучения» ИК-сенсора и перевода его сырых значений АЦП в реальные сантиметры.

**Датчики и пины:**
- **HC-SR04 (Ультразвук):**
    - **D9:** Trig (запуск импульса)
    - **D10:** Echo (прием эха)
- **TCRT5000 / KY-033 (ИК-датчик):**
    - **A0:** Analog Out (считывание интенсивности отражения)
- **Индикация:**
    - **D13:** Встроенный светодиод (статус калибровки)

### Структура системы и логика работы

Система разделена на две части: **прошивку микроконтроллера** (сбор данных и контроль качества) и **Python-скрипт** (математическая обработка и визуализация).

**Логика контроля данных на стороне Arduino:**
Для обеспечения точности модели сбор данных не завершится, пока не будут выполнены условия «плотности» измерений:
- **Диапазон:** Задается пользователем через Serial (например, от 3 до 10 см).
- **Покрытие (Coverage):** Данными должно быть заполнено не менее 90% выбранного диапазона.
- **Целостность (Gaps):** В собранных данных не должно быть «дыр» (пропусков) более 2 см подряд.

Данные отслеживаются с помощью массива `visited[200]`, где каждый индекс соответствует пройденному сантиметру.

### Основные функции прошивки

- `getUltrasonicDistance()`: производит замер эталонного расстояния. Использует скорость звука 0.0343 см/мкс для расчетов.
- `checkDataSufficiency()`: анализирует массив `visited`, проверяя условия покрытия и максимального пропуска. Возвращает `true`, когда модель можно строить.
- `getDistanceIR(rawADC, coeffs, degree)`: универсальная функция для применения полученной модели. Вычисляет расстояние на основе коэффициентов полинома любой степени.

### Алгоритм калибровки и команды

Система управляется командами через Serial Port на скорости 9600 бод:

1. **Инициализация:** Команда `CAL <min> <max>` (например, `CAL 3 12`) переводит устройство в режим калибровки.
2. **Сбор данных:** Пользователь плавно перемещает объект перед датчиками. Arduino отправляет в порт пакеты вида `DATA <IR_Value> <US_Distance>`.
3. **Завершение:** При достижении нужной плотности данных Arduino отправляет флаг `DONE` и подтверждает успех 10-кратным миганием светодиода.

### Математическое моделирование (Python)

Скрипт на стороне ПК принимает поток данных и выполняет аппроксимацию методом наименьших квадратов. 
- **Полиномиальная регрессия:** Система строит три модели (1-й, 2-й и 3-й степени).
- **Визуализация:** С помощью `matplotlib` строится график, на котором отображаются реальные точки измерений и наложенные на них кривые моделей.
- **Экспорт:** Скрипт выводит готовые массивы коэффициентов в формате C++, которые можно сразу вставить в код робота для автономной работы.

### Мониторинг и диагностика

В процессе работы в консоль выводится статус каждой собранной точки. Если ИК-датчик выдает некорректные значения (например, постоянный 0 или шум), Python-скрипт выдаст предупреждение о плохой обусловленности модели (`RankWarning`).

Успешная калибровка гарантирует, что даже дешевый ИК-датчик линии сможет работать как точный дальномер в заданном диапазоне.
